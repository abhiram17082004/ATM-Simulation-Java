# ATM Simulation System 💳

A simple **console-based ATM Simulation System built using Core Java and Object-Oriented Programming (OOP)**. This project simulates basic ATM operations and demonstrates how Java classes, interfaces, and methods can be used to build a real-world application.

## 🚀 Features

- 💰 **Check Balance** – View the available account balance.
- 💵 **Withdraw Money** – Withdraw money from the account.
- 💳 **Deposit Money** – Deposit money into the account.
- 🔄 **Menu-Driven Interface** – Interact with ATM operations through a console menu.
- ✅ **Basic Validation** – Handle transaction inputs and account operations.

*Note: The features listed above describe the intended ATM functionality; ensure they match your implementation.*

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Core Concepts:** Object-Oriented Programming (OOP)
- **Interface:** Java console
- **Tools:** JDK and any Java-compatible IDE

## ⚙️ Getting Started

### Prerequisites

Install the Java Development Kit (JDK). Verify the installation using:

```bash
java -version
javac -version
```

### Clone the Repository

```bash
git clone https://github.com/abhiram17082004/ATM-Simulation-Java.git
cd ATM-Simulation-Java
```

### Compile the Project

```bash
javac *.java
```

### Run the Application

```bash
java AtmMain
```

If your source files declare a package, compile and run them using the appropriate package structure.
